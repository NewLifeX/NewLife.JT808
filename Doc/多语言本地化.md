# 多语言本地化

NewLife.JT808 采用 NewLife.Core v12 的运行时本地化机制：**英文原文为键**，译文以编译期词表内嵌，缺少译文时自动回退英文。协议帧、字段与枚举名不受语言影响。

## 支持语言

当前内置 11 种语言，与 README 语种一一对应：

| 语言 | 区域代码 | 词表文件 |
|------|----------|----------|
| 简体中文 | `zh-Hans` | `Locales/zh-Hans.yml` |
| 繁體中文 | `zh-Hant` | `Locales/zh-Hant.yml` |
| 英语（源文） | `en` | 无（键即英文原文） |
| 西班牙语 | `es` | `Locales/es.yml` |
| 德语 | `de` | `Locales/de.yml` |
| 日语 | `ja` | `Locales/ja.yml` |
| 法语 | `fr` | `Locales/fr.yml` |
| 葡萄牙语 | `pt` | `Locales/pt.yml` |
| 俄语 | `ru` | `Locales/ru.yml` |
| 韩语 | `ko` | `Locales/ko.yml` |
| 阿拉伯语 | `ar` | `Locales/ar.yml` |

区域变体按父级匹配：`zh-CN` 命中 `zh-Hans`，`zh-TW`/`zh-HK`/`zh-MO` 命中 `zh-Hant`，`fr-CA` 命中 `fr`。

## 使用方式

```csharp
using System.Globalization;
using NewLife;

// 默认跟随 CultureInfo.CurrentUICulture；也可显式固定
Localization.Culture = CultureInfo.GetCultureInfo("ja");

// 日志语言可独立固定，避免随请求语言变化
Localization.LogCulture = CultureInfo.GetCultureInfo("zh-Hans");

// ASP.NET Core 宿主可按 Accept-Language 识别请求语言
using var scope = RequestCultureScope.Create(Request.Headers.AcceptLanguage);
```

- 异常消息在抛出时按 `Localization.Culture` 翻译；
- 日志由 NewLife.Core 的 `Logger.FormatMessage` 按 `LogCulture ?? Culture ?? CurrentUICulture` 翻译，因此库内日志一律写英文源文；
- 所有单词条缺失或占位符格式化失败时回退英文原文，不会因翻译问题产生新异常。

## 词表格式

`Locales/*.yml` 是严格 YAML 子集：每行一条 `"英文原文": "译文"`，仅支持双引号字符串与 `\\ \" \n \r \t \uXXXX` 转义，空行与 `#` 注释被忽略。占位符必须与英文原文完全一致。

```yaml
# zh-Hans 译文。键为英文源文，缺失时运行期回退英文。
"Unsupported type [{0}].": "不支持的类型[{0}]。"
"Heartbeat => {0}": "心跳 => {0}"
```

构建期由 NewLife.Core 随包分发的源生成器读取词表：校验语法、重复键与占位符，生成压缩语言表并在模块初始化时注册。运行时只做字典查找，不依赖 ResourceManager 与卫星程序集，**原生支持 AOT**。

## 程序集与 NuGet 元数据

程序集标题与描述同样是可本地化的展示文本，采用“英文源文 + 词表 + 展示层翻译”三段式：

- `csproj` 的 `AssemblyTitle` / `Description` 使用英文源文，并把**同一串**作为 key 写入 `Locales/*.yml`，11 种语言全部提供译文；
- 反射读取 `AssemblyTitleAttribute` / `AssemblyDescriptionAttribute` 后，在展示处调用 `L.T(value)` 即可得到当前语言文本；
- `PackageDescription` 承接中英双语包说明，`Description` 保持纯英文供反射使用；NuGet 站点的包元数据不随界面语言切换；
- `Tools/Scripts/check-locales.ps1` 的孤儿键扫描已把 `.csproj` 纳入源文范围，标题/描述词条不会被误判。

## 异常与日志

- 异常消息统一写 `throw new XException(L.T("English template {0}.", arg))`；`L.T` 字面量必须有词条，脚本会报“缺少词条”。
- 日志统一写**英文格式串 + 参数**，不要用字符串插值；NewLife.Core 的 `Logger.FormatMessage` 按 `LogCulture ?? Culture` 翻译，未收录的键回退英文原文。
- 日志语言可用 `Localization.LogCulture` 独立固定，避免随请求语言变化；界面语言与日志语言互不影响。

## 新增词条

1. 在代码中以英文源文调用 `L.T("...")`（异常）或直接写英文日志文案；
2. 在全部 `Locales/*.yml` 追加同名键；
3. 运行 `pwsh -File Tools/Scripts/check-locales.ps1 -LocaleDir Newlife.JT808/Locales -SourceDir Newlife.JT808,JT808.Server` 校验键集合、占位符与孤儿键；
4. 运行单元测试（`ProtocolCoverageTests` 覆盖 11 种语言注册与翻译）。

## 新增语言

1. 新增 `Locales/{区域代码}.yml`，覆盖 `zh-Hans.yml` 的全部键；
2. 运行 `Tools/Scripts/check-locales.ps1` 校验一致性；
3. 同步更新 `readme-languages.json` 与 `readme-metrics.json` 的 `localeCount`，运行 `Tools/Scripts/sync-readme-metrics.ps1`。
